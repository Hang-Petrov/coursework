# Курсова робота
Курсова робота з дисципліни «Дослідження операцій в інформаційно-управляючих системах», 2026. Беркза, Реброва, Ткаченко, Сичов (Артем)

Реалізація жадібного алгоритму (ЖА) та алгоритму стохастичного жадібного вибору (СЖВ)
для задачі планування розробки компонентів програмного продукту.
 
## Як запустити
 
Двічі клацнути на `index.html`. Програма відкриється у браузері - все працює локально,
без сервера, без встановлень.
 
Підтримуються Chrome, Firefox, Edge.
 
## Структура
 
- `index.html` - інтерфейс
- `styles.css` - стилі
- `algorithms.js` - ЖА і СЖВ
- `generator.js` - генератор випадкових ІЗ
- `experiments.js` - 4 експерименти з п. 3.3
- `ui.js` - обробники подій, Гантт-діаграма, графіки

## Як користуватися
 
**Вкладка «Індивідуальна задача».** Можна задати n, m і самому ввести `tᵢ`, `uᵢ` та пари
передування у форматі `i→j`, або натиснути «Згенерувати випадково». Кнопка
«Завантажити приклад (n=6)» - це задача з п. 2.4 курсової, на ній ЖА має давати Z = 159.
Кнопки «Розв'язати» запускають алгоритми; результат - Гантт-діаграма та значення Z і τ.
 
**Вкладка «Експерименти».** Обираєш тип експерименту (вплив N, β, або n на точність/час),
задаєш параметри і набір значень досліджуваного параметра, тиснеш «Запустити». Після
завершення можна експортувати результати в CSV.
